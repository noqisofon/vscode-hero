# Idle Hero (vscode-hero)

ヒーローがエディタの隅で勝手に冒険し続ける放置系ゲームの VSCode 拡張。

- **ステータスバー**（右下）に HP / Lv / 階 / 所持金を常時表示。クリックで冒険パネルを開く。
- **パネル「Hero」**（ターミナルと同じ下部パネル）でヒーローと敵の戦闘アニメ・ログを観戦。
- 自動で戦闘 → 経験値・ゴールド獲得 → レベルアップ → 装備を自動購入。10 階ごとにボス（倒せる見込みが立つまで、その階の手前で鍛えてから挑む）。
- やられると所持金の 20% を失い 3 階退却。🧪 回復薬（50G）は手動で使える。
- VSCode を閉じている間も進行（最大 3600 ターン分）。再開時に「留守中の成果」を通知。

## コマンド
| コマンド | 内容 |
|---|---|
| `Hero: 冒険を見る` | パネルを開く |
| `Hero: 回復薬を使う (50G)` | HP を全回復 |
| `Hero: 最初からやり直す` | セーブを初期化 |

## 設定
- `hero.name` ヒーローの名前
- `hero.tickSeconds` 1 ターンの秒数（既定 1）

## 開発
ビルド不要（プレーン JS）。`F5` で Extension Development Host を起動。

```
npm test   # ゲームロジックと拡張の起動テスト
```
